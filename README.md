# 7-Eleven Backend

Backend API cho hệ thống 7-Eleven được xây dựng bằng Spring Boot.

Project hỗ trợ:

- Quản lý sản phẩm
- Upload ảnh sản phẩm lên Cloudinary
- Tạo đơn hàng
- Xem danh sách đơn hàng
- Tìm kiếm sản phẩm realtime
- RESTful API
- MySQL Database

---

# Tech Stack

- Java 17
- Spring Boot 3
- Spring Web
- Spring Data JPA
- MySQL
- Cloudinary
- Maven
